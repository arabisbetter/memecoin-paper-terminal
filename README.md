# Memecoin Paper Terminal

PAPER is a Solana memecoin paper-trading terminal using live public market data and simulated **PAPER SOL** balances.

Public beta features include Spot, Pulse, Portfolio, Wallet Tracker, Token Intelligence, Trader Profiles, Evaluation, PAPER Rewards, scanners, smart-money views, watchlists, journals, workspaces, and community/leaderboard tools.

**PAPER-only beta:** real-money trading, funded accounts, custody, KYC payout flows, real SOL prizes, payouts, and token-purchase flows are disabled and are not part of the public product.
